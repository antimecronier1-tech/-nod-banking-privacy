# Nod Banking — Privacy Policy **Last updated: November 19, 2026** Nod Banking is a personal, non-commercial application used by its owner to access and analyze their own bank account information through Enable Banking. **Data collected:** Account balances, transaction history, transaction dates, amounts, currencies, and transaction descriptions. **Purpose:** Personal financial monitoring, automated bookkeeping, and financial notifications through n8n. **Data storage:** Banking information is processed and stored in the owner's private automation infrastructure. **Data sharing:** Banking data is not sold or shared with advertisers. Enable Banking and the connected financial institution process information as necessary to provide the banking connection. **Data security:** Banking information is accessed through authorized, encrypted API connections. Access is restricted to the application owner. **Data retention:** Information is retained only as necessary for personal financial monitoring and may be deleted by the owner. **Contact:** The application owner can be contacted through the GitHub repository associated with this policy.
